Introduction

Context

This vocabulary is supporting MLDCAT-AP, a specialisation of the DCAT application profile for European data portals [[DCAT-AP]] for machine learning models and data. The terms defined in this namespace are defined as broad as possible for wider reuse but are scoped to the needs of MLDCAT-AP. All terms in this vocabulary have therefore a strong connection with MLDCAT-AP.

Revision history

This namespace document was created during the process of aligning the MLCAT-AP profile with DCAT-AP 3.x and the SEMIC style guide in 2026.

Abstract

The MLDCAT-AP vocabulary supports the MLDCAT-AP profile. The namespace for this vocabulary is http://data.europa.eu/it6/ . It is under maintenance by the SEMIC action, Interoperable Europe.

Status

This vocabulary has the status Onbekend published at 2023-01-13.

Information about the process and the decisions involved in the creation of this specification are consultable at the Changelog.

Conformance Statement

In order to conform to this vocabulary the usage of the terms MUST:
  • Be in line with the provided definitions
  • Satisfy the formal constraints such as domain and ranges restrictions, if present
When reusing the terms, the reuse principles of the SEMIC Style Guide SHOULD be followed.

To make the properties widely reuseable the domain and ranges are usually very open. For any kind of entity, the class rdfs:Resource is used. For any kind of value, rdfs:Literal is used. In the RDF ecosystem these are the universal denominators.
